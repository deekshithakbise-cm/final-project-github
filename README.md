## Simple Interest Calculator

### Purpose
The **Simple Interest Calculator** helps users quickly calculate the interest earned or owed on a loan or investment over a specific period. 

### Inputs
To run the calculation, the script requires the following three inputs:
*   **Principal amount:** The initial amount of money invested or borrowed.
*   **Interest rate:** The annual interest rate expressed as a percentage.
*   **Time period:** The duration of the loan or investment in years.

### Formula
The calculation is based on the standard simple interest formula:
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

### How to Use It
1.  **Run the script:** Open your terminal or command prompt, navigate to the project directory, and execute the script using Python:
    ```bash
    python simple_interest.py
    ```
2.  **Enter the values:** Follow the interactive command-line prompts to type in your principal, rate, and time.
3.  **View results:** The script will instantly calculate and display the total interest amount and the final balance.
